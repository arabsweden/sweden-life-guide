# دليل الحياة في السويد | Sweden Life Guide
**Brand:** RAED SHIHAB — Arab Sweden Since 2007

منصة إرشادية عربية متكاملة وموثوقة لمساعدة المقيمين والقادمين الجدد في السويد على الحصول على إجابات معتمدة، خطوات عمل موثقة، وقوائم وثائق رسمية مستندة حصرياً لمصادر الجهات الحكومية السويدية.

---

## 🌟 مميزات المنصة

- **إدخال متعدد الوسائط**: طرح الأسئلة بالتكست، التسجيل الصوتي المباشر، أو رفع صور/مستندات (PDF, DOCX, JPG).
- **فحص وتصفية البيانات الحساسة**: كشف تلقائي للرقم الشخصي السويدي (Personnummer) وتنبيه المستخدم لتشفيره قبل الإرسال.
- **ربط موثوق بمصادر رسمية**: الاعتماد حصراً على مواقع النطاقات الحكومية (.se) مثل Migrationsverket, Skatteverket, Försäkringskassan, Arbetsförmedlingen, Socialstyrelsen, 1177, CSN وغيرها.
- **نتائج هيكلية واضحة**: خلاصة مباشرة، الشروط المفترضة، خطوات مرتبة، قائمة التحقق من الوثائق، والجهة المختصة.
- **تصدير ومشاركة**: تنزيل تقارير PDF تدعم العربية RTL، وإرسال النتيجة بالبريد بعد الموافقة.
- **دعم اللغات الثلاث**: العربية (افتراضية وRTL)، السويدية، والإنجليزية.
- **سجل أسئلتي وإدارتها**: حفظ، بحث، تصفية، مفضلة، وإعادة فتح الاستفسارات.
- **لوحة إدارة متكاملة (`/admin`)**: إدارة الأقسام، سجل المصادر الرسمية، طابور المراجعة، والتحليلات المجهولة.

---

## 🚀 الانتقال من Demo إلى Production

لتحويل المنصة من وضع المعاينة التجريبي (Demo Mode) إلى الإنتاج الكامل:

1. **إعداد المصادقة وقاعدة البيانات**:
   - ربط مشروعي Firebase Auth وCloud Firestore لحفظ بيانات المستعملين والأسئلة بسحاب موثوق.
   - نشر قواعد أمان Firestore التي تمنع قراءة أسئلة المستخدمين الآخرين.

2. **إعداد التخزين وسياسة الحذف**:
   - تهيئة Firebase Storage أو Google Cloud Storage لحفظ المرفقات المؤقتة والمشفرة.
   - تفعيل وظيفة الحذف التلقائي للمرفقات بعد المعالجة (Retention Policy).

3. **إضافة مفتاح Gemini في الخادم**:
   - إدخال مفتاح `GEMINI_API_KEY` في إعدادات البيئة بالخادم فقط دون تسريبه للمتصفح.
   - التأكد من استخدام موديل `gemini-3.6-flash`.

4. **إعداد مصدر المعرفة الرسمي والفهرسة**:
   - ربط الفهرس بشبكة RAG أو RAG Vector Store يحتوي أحدث صفحات النطاقات الرسمية المعتمدة.

5. **إعداد خدمات PDF والبريد**:
   - ربط خدمة SendGrid / AWS SES لإرسال الرسائل الفعلية عند طلب المستخدم.

6. **الفحص والأمان المسبق**:
   - تشغيل اختبارات الاختراق وPrompt Injection للحماية الكاملة.
